# Alethe aiur-v0.1.0-beta (Aiur fork)

Prerelease build of the **AiurArtanis/alethe-agents** fork.

## Included
- Grok Build and Codewhale as native agent providers (`feat/grok-build-codewhale`)
- zh-CN locale and Chinese README (`feat/zh-cn-i18n`)

## Notes
- This is an **Aiur fork** release marker (`aiur-v*`). It is **unrelated** to upstream Alethe 1.7.x version numbering.
- Windows x64 installer (NSIS / setup.exe) is the primary artifact for this beta.
- Updater signing keys are fork-specific; do not mix with upstream Kc1t release signatures.

## Install
Download the Windows `.exe` (NSIS) asset from this GitHub Release and run it.
